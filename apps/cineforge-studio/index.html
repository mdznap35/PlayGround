كيف تستخدم الاستوديو؟

اكتب فكرة الفيديو، اختر النمط والأبعاد والمدة، ثم أنشئ مخططاً أولياً. عدّل نص كل مشهد ومدته واتجاهه البصري، ثم نزّل JSON.

ملف JSON هو وصف إنتاج الفيديو، وليس الفيديو نفسه. بعد رفعه إلى مجلد jobs وتشغيل GitHub Actions، سيُنتج المحرك ملف MP4.

المعالجة الحالية قائمة على Motion Graphics. توليد لقطات AI واقعية يحتاج موصل GPU منفصلاً، وهو غير مفعّل في هذا الإصدار.
