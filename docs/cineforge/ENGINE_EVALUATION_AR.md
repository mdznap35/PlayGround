# CineForge — محركات الإنتاج والتكاملات المفتوحة

**تاريخ التقييم:** 2026-11-03  
**الفرع:** `feat/cineforge-cinematic-media-v2`  
**القرار:** دمج انتقائي، مجاني قدر الإمكان، بلا تنزيل نماذج قبل موافقة صريحة.

هذا الملف يفرّق بين محركات تعمل فعلياً، ومحركات تم تقييمها كمرشحين، ومحركات مؤجلة. وجود رابط أو دراسة لا يعني أن المحرك مثبّت أو مدمج.

## 1. المحركات العاملة الآن

| المحرك | دوره الحالي | مكان التنفيذ | الحالة |
|---|---|---|---|
| Pillow | رسم الإطارات، النصوص، التدرجات، وتركيب الصور | Python على عامل الرندر | فعّال |
| FFmpeg | تركيب المشاهد والحركة والانتقالات والصوت وإخراج MP4 | GitHub Actions CPU | فعّال |
| FFprobe | فحص الترميز والأبعاد ومعدل الإطارات والمدة ومسارات الصوت | GitHub Actions CPU | فعّال |
| GitHub Actions | تنفيذ التحقق والرندر ورفع MP4 وتقرير الجودة | عامل مستضاف CPU | فعّال، خاضع لحصص المنصة |
| Render Static Site | استضافة واجهة المتصفح ومخطط القصة | Render | فعّال؛ لا ينفذ الرندر |

**ليس لدينا حالياً:** توليد فيديو واقعي من النص، أو توليد صور AI، أو تحويل نص إلى كلام، أو تفريغ كلام آلي. ولا يوجد نموذج ذكاء اصطناعي محمّل داخل المستودع.

## 2. مرشح تحويل الكلام إلى نص — Whisper.cpp

**التقييم: المرشح الأول لتفريغ التعليق الصوتي العربي وإنتاج مسودة ترجمة.**

- مشروع C/C++ مفتوح المصدر بترخيص MIT، ويدعم CPU-only inference ومنصات Android وWebAssembly.
- النماذج متعددة اللغات تدعم العربية؛ يجب تجنّب ملفات `.en` لأنها مخصصة للإنجليزية.
- أحجام النماذج المنشورة: `tiny` نحو 75 MiB مع ذاكرة تشغيل تقارب 273 MB، و`base` نحو 142 MiB مع ذاكرة تقارب 388 MB. `small` يقارب 466 MiB، وهو أكبر من اللازم كبداية.
- يمكن استخدامه لاحقاً لتوليد مسودة SRT/VTT، ثم يراجع المستخدم التوقيت والنص يدوياً قبل التصدير.
- دعم Android في المشروع لا يعني أن تجربة الهاتف لدينا قد اختُبرت أو أن الأداء مضمون على كل جهاز.

**قرار التنفيذ:** تصميم موصل ASR مستقل قابل للتعطيل. لا تنزيل الآن. قبل تجربة فعلية نعرض الحجم الدقيق للملف المختار، ومتطلبات الذاكرة، ونطلب موافقة المستخدم. البدء المنطقي — بعد الموافقة — هو نموذج `tiny` متعدد اللغات ثم تقييم جودة العربية على عينة يملك المستخدم حق استخدامها.

المراجع:
- https://github.com/ggml-org/whisper.cpp
- https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md

## 3. مرشح تحويل النص إلى كلام — Piper

**التقييم: مرشح عملي لإنتاج تعليق صوتي محلي، مع تحفظ قانوني وجودة يجب اختبارهما.**

- قائمة الأصوات الرسمية تتضمن العربية الأردنية `ar_JO`.
- يحتاج كل صوت إلى ملف ONNX وملف إعداد JSON؛ حجم ملف الصوت العربي المحدد لم يُثبت بعد، لذلك لا نذكر رقماً تخمينياً.
- مستويات الأصوات المنشورة تتراوح تقريباً من 5–7 ملايين معلمة لـ `x_low` إلى 28–32 مليوناً لـ `high`؛ هذا ليس بديلاً عن قياس الحجم الفعلي للملف.
- المشروع الحالي `piper-tts` يعلن ترخيص GPL-3.0-or-later. كما تحذر وثائق الأصوات من أن ترخيص كل صوت قد يختلف ويجب قراءة بطاقة النموذج نفسه.
- الترخيص GPL يستلزم مراجعة توافقه مع طريقة توزيع CineForge قبل تضمينه في إصدار موزّع. لا يكفي أن يكون المحرك مفتوح المصدر.
- يجب اختبار مخارج العربية والنطق والتشكيل والوقفات وجودة الصوت قبل اعتماده للإنتاج.

**قرار التنفيذ:** مرشح تجريبي للمرحلة الصوتية، وليس اعتماداً نهائياً. لا تثبيت ولا تنزيل صوت حتى مراجعة التوافق الترخيصي وإظهار الحجم الدقيق للصوت والحصول على الموافقة.

المراجع:
- https://github.com/OHF-Voice/piper1-gpl
- https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/VOICES.md
- https://github.com/OHF-Voice/piper1-gpl/blob/main/setup.py

## 4. محرك الصور والفيديو التوليدي — ComfyUI

**التقييم: قوي كطبقة توليد اختيارية، لكنه ليس حلاً مجانياً مضمون الاستضافة.**

- ComfyUI يوفر واجهة عقدية وواجهات API وسير عمل قابل للحفظ، ويدعم نماذج صور وفيديو متعددة.
- المشروع الأساسي GPL-3.0.
- النماذج الفعلية ملفات منفصلة وقد تكون كبيرة جداً؛ لا يعني أن البرنامج نفسه خفيف أو أن كل نموذج مجاني من ناحية الترخيص أو الموارد.
- الوثائق تذكر أن Comfy Cloud الرسمية مدفوعة؛ تشغيل محلي يحتاج موارد الجهاز، وتشغيل نماذج الفيديو عادةً يحتاج GPU وذاكرة مناسبة.
- يمكن بناء موصل Adapter يرسل مهمة إلى خادم ComfyUI يملكه المستخدم أو إلى خدمة مجانية موثّقة الشروط. يجب فصل ذلك عن محرر CineForge الأساسي كي لا يتعطل عند غياب GPU أو انتهاء الحصة.

**قرار التنفيذ:** تأجيل دمج محرك التوليد الفعلي حتى يوجد خادم GPU مجاني مثبت التوفر أو جهاز مستخدم مناسب ومصرّح به. لا نعد بتوليد غير محدود مجاناً، ولا ننزّل نماذج.

المراجع:
- https://github.com/Comfy-Org/ComfyUI
- https://docs.comfy.org/
- https://support.comfy.org/articles/2703236295-comfy-api-deploy-your-comfyui-workflow-as-an-api

## 5. بنية الموصلات التي سنستخدمها

بدلاً من ربط التطبيق بمحرك واحد مباشرة، تكون لدينا واجهات منفصلة:

1. **ASR Adapter:** ملف صوت → نص وتوقيتات أولية → SRT/VTT قابل للتحرير.
2. **TTS Adapter:** نص وملاحظات نطق → ملف WAV/MP3 → فحص مدة وصوت.
3. **Visual Generation Adapter:** وصف اللقطة → صورة/مقطع → فحص الملف والمصدر والترخيص.
4. **Renderer Adapter:** مشاهد وأصول ومسارات صوت → FFmpeg → MP4 وتقارير QA.

كل موصل يجب أن يعلن: الاسم والإصدار، حالة التوفر، طريقة التشغيل، احتياج CPU/GPU/RAM، حجم النماذج، الرخصة، حد الاستخدام أو التكلفة، وسبب فشل المهمة. ويجب أن يعمل المحرر والرندر الأساسي حتى لو كانت كل موصلات AI معطلة.

## 6. ترتيب التنفيذ المقترح

| الترتيب | الإضافة | السبب | شرط البدء |
|---|---|---|---|
| 1 | محرر SRT/VTT يدوي مع توقيتات وفحص عربي RTL | فائدة مباشرة بلا نموذج أو GPU | ضمن المرحلة الحالية |
| 2 | موصل Whisper.cpp للتفريغ وإنشاء مسودة ترجمة | يختصر النسخ اليدوي ويمكن تشغيله CPU | موافقة منفصلة على تنزيل نموذج 75 MiB أو 142 MiB بعد إظهار الحجم |
| 3 | موصل Piper للتعليق | يضيف صوتاً محلياً للعربية | مراجعة GPL وبطاقة ترخيص الصوت وقياس حجمه ثم الموافقة |
| 4 | محرك صور/فيديو توليدي عبر ComfyUI | يرفع القدرة البصرية | خادم GPU موثوق وحصة/تكلفة ورخص نماذج مثبتة |
| 5 | مزج صوتي متقدم وDucking وفحص الصمت والذروة | جودة إخراج وتسليم | بعد استقرار المسارات والتوقيت |

## 7. قواعد لا نتجاوزها

- لا تنزيل نموذج أو صوت أو مجموعة ملفات كبيرة في الخلفية.
- قبل التنزيل: اسم الملف، الحجم الدقيق، مساحة التخزين المطلوبة، الرخصة، ومتطلبات الذاكرة؛ ثم موافقة صريحة.
- لا تخزين تسجيلات صوت المستخدم أو ملفاته الخاصة في المستودع العام.
- لا إرسال ملفات المستخدم إلى خدمة خارجية دون اختيار واضح وإظهار وجهة الملف.
- لا وصف أي خدمة بأنها مجانية إلا بعد التحقق من حدودها وشروطها الحالية.
- فشل الموصل الاختياري لا يجب أن يمنع إنتاج MP4 عبر المحرك الأساسي.
- كل لقطة مولدة أو مستوردة تحفظ بيانات المصدر والترخيص قدر الإمكان.

## 8. القرار الحالي

**الاستثمار الأفضل فوراً:** بناء محرر ترجمة وصوت متين فوق FFmpeg، ثم إدخال Whisper.cpp كميزة اختيارية بعد الموافقة على نموذج صغير. Piper مرشح عربي واعد لكنه يحتاج تدقيق ترخيص وتقييم صوت. ComfyUI يبقى تكاملاً مستقبلياً مشروطاً بوجود GPU مجاني حقيقي أو خادم يملكه المستخدم.

تم إعداد هذه المقارنة دون تثبيت أي محرك إضافي ودون تنزيل أي نموذج.
