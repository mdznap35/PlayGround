# Asset pipeline

## Directory contract
```
assets/
  source/        # drop curated packs here (never shipped directly)
  ready/         # optimized build output + manifest.json (generated)
  licenses/      # OFL/CC0/PD texts — one per bundled asset
  audio/sfx|music|voices/   # curated runtime audio (ogg/mp3)
  data/          # fixtures + schemas (open-meteo-sample.json)
  characters|creatures|environments|props|buildings|nature|
  science|workshop|vehicles|space|ui|textures|particles|references/
public/
  fonts/         # woff2 served + precached
  icons/         # PWA icons (generated by scripts/make-icons.mjs)
  audio/ambience/# precached beds
```

## Formats & budgets (mobile-first)
| Kind | Format | Budget | Notes |
|---|---|---|---|
| UI/env art | WebP q80, ≤1024px longest edge | ≤120KB/file | PNG fallback only for icons |
| Icons | PNG 192/512 | ≤25KB total | generated, committed |
| Fonts | woff2 subsets (arabic+latin) | ≤80KB total (now 73KB) | `@font-face` + `font-display: swap` |
| SFX | ogg Vorbis mono 44.1k | ≤40KB/file, ≤10 files | Howler sprite later |
| Ambience | ogg 96kbps mono, loopable | ≤4MB total (now 4.6MB — trim or re-encode to ≤3MB before release) | fade in/out 2s |
| Voice lines | ogg/mp3 mono 32kbps | ≤15KB/line | line-addressed manifest |
| Textures/particles | procedural canvas first | — | bitmap only with measured need |

## Commands
- `node scripts/make-icons.mjs` → regenerates `public/icons/`
- `node scripts/optimize-assets.mjs` → `assets/source/**.{png,jpg}` → `assets/ready/**.webp` + `manifest.json` (env: `NOVA_IMG_MAX`, `NOVA_IMG_Q`)
- Runtime loads: precache (shell/fonts/ambience) → lazy (voice packs per zone) → on-demand (API w/ fixture fallback)

## Manual steps (need a browser click, no account)
1. Kenney.nl CC0 packs (e.g. Interface Sounds): open pack page → Download → unzip → keep ≤10 needed files → drop in `assets/source/sfx/` → run optimizer → move keepers to `assets/audio/sfx/` → add license row + `assets/licenses/CC0-kenney.txt` (all Kenney assets are CC0; keep the pack's license note).
2. Freesound.org (needs free API key → user action): only if Kenney gaps remain.

## Rules
- Never commit 5 versions of one file; `source/` + `ready/` + runtime copy max.
- Every runtime asset must be reachable offline (precache or lazy-cache with fallback).
- `assets/ready/manifest.json` is the source of truth for what shipped.
